# Extension examples

Find the runnable files and installation steps in [examples/extensions](../../../../examples/extensions/README.md): a topic digest, topic deletion and an activity roster. This directory is a pointer, not a second set of examples.

For a minimal route you can install immediately, use the [extension guide](../../pages/docs/extensions.md). The seed’s `app/ext/standup.ts` and `app/ext/subscriptions/` demonstrate a consistent report and persistent webhook delivery.
